# 📖 About

Expiration Tracker is an open-source desktop application designed to help users organize groceries, monitor expiration dates, and reduce unnecessary food waste.

The project is also a personal software engineering journey where I am learning professional development practices including:

- Java
- JavaFX
- SQLite
- Database Design
- Object-Oriented Programming
- Git & GitHub
- OCR Integration
- Software Architecture
- Clean Code Principles

Rather than being just another CRUD application, the goal is to build a practical inventory management system that can eventually scale beyond personal household use.

---

# 🎯 Vision

The long-term vision is to create an intelligent inventory management platform capable of serving:

- 🏠 Households
- 🛒 Convenience Stores
- 🏫 Schools
- 🏥 Institutions
- 🍽 Restaurants
- 🍎 Food Banks

The project aims to reduce food waste while making inventory management simple, affordable, and accessible through open-source software.
